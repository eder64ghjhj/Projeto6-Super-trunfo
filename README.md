# 🃏 Super Trunfo — Batalha de Empresas Tech

Jogo de cartas Super Trunfo temático com as maiores empresas de tecnologia do mundo. O jogador compete contra a CPU escolhendo atributos como receita, usuários e índice de inovação.

## 🎮 Como Jogar

1. Você recebe uma carta com dados reais de uma empresa tech
2. Escolha o atributo que acredita ser superior ao da CPU
3. O maior valor vence a rodada e fica com as cartas
4. Vence quem colecionar todas as cartas!

## 🏢 Empresas no Baralho

Google, Apple, Microsoft, Amazon, Meta e outras gigantes da tecnologia com dados reais de mercado.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
